# Portfolio Frontend 🎨

The client-side application for my personal developer portfolio, built with modern web technologies. 
This frontend consumes a custom FastAPI backend and demonstrates strict typing, component-based architecture, and responsive design.

## 🛠️ Tech Stack

* **Framework:** React 18
* **Language:** TypeScript
* **Build Tool:** Vite
* **Styling:** Tailwind CSS v4

## 🚀 Getting Started

### 1. Installation
```bash
npm install
```

### 2. Run the Development Server
```bash
npm run dev
```

## 🧠 AI-Assisted Development
This project maintains strict AI collaboration rules defined in `GEMINI.md` to ensure code quality and educational growth. The frontend relies on `api-contract.json` to maintain type-safe API calls.
